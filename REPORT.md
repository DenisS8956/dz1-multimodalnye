# ДЗ 1. Отчёт об исправленных ошибках

**Вариант:** seed 42. В исходном `dz1-bughunt.ipynb` — три семантические ошибки. Номера строк ниже приведены для исходной ячейки кода № 3 (нумерация ячеек с нуля).

| № | Локализация | Механизм нарушения | Исправление |
|---|---|---|---|
| 1 | `sinusoidal_positional_encoding`, строка 39 | `torch.arange(1, length + 1)` сдвигает все абсолютные позиции на единицу. Токен с индексом `t` получает синусоидальный вектор для `t+1`. Например, нулевая позиция должна иметь нули в синусных каналах и единицы в косинусных, но код вычисляет значения для позиции 1. Формы тензоров остаются правильными, однако численные значения не соответствуют формуле позиционного кодирования. Сам по себе постоянный сдвиг не обязательно препятствует обучению; ошибка обнаруживается по проверке математического определения. | `position = torch.arange(length, dtype=torch.float32).unsqueeze(1)` |
| 2 | `LayerNorm.forward`, строки 60–61 | Среднее и дисперсия вычисляются по `dim=0` (ось батча) вместо последней оси признаков. Поэтому нормировка одного токена зависит от других примеров, попавших в тот же батч, хотя LayerNorm должен обрабатывать каждый токен независимо. При батче из одного примера дисперсия по оси 0 равна нулю: нормированное представление вырождается, и нарушается передача информации через блок. | Для `mean` и `var` установить `dim=-1`, оставить `keepdim=True` и `unbiased=False`. |
| 3 | `scaled_dot_product_attention`, строка 101 | У оценок внимания форма `(batch, heads, query, key)`. `softmax(dim=-2)` распределяет вероятности между запросами, а не между доступными ключами для каждого запроса. В результате сумма весов по последней оси не равна единице и нарушается вычисление взвешенной суммы `V`. При причинной маске нормирующий знаменатель для раннего запроса может зависеть от оценок более поздних запросов: появляется косвенная утечка информации из будущего. | `weights = torch.softmax(scores, dim=-1)` — нормализация по ключам. |

## Результаты проверки

В обоих ноутбуках выполнены все **17 из 17** открытых проверок. Код тестов оставлен без изменений относительно предоставленных преподавателем файлов.

После исправлений проведено обучение модели на корпусе из оригинального ноутбука: **600 шагов**, **19 символов словаря**, **400 640 параметров**, seed обучения **0**.
