# ДЗ 1 — Внимание своими руками

Два ноутбука с реализацией механизма внимания и исправлением ошибок в символьной модели трансформера. Вариант ошибок: **seed 42** (три ошибки).

## Содержимое

| Файл | Назначение |
|---|---|
| [`dz1-attention.ipynb`](dz1-attention.ipynb) | Реализация `split_heads`, `merge_heads`, `scaled_dot_product_attention` и `TransformerBlock.forward`; 17 тестов |
| [`dz1-bughunt.ipynb`](dz1-bughunt.ipynb) | Исправленные ошибки, 17 тестов, обучение, график потерь и генерация текста |
| [`REPORT.md`](REPORT.md) | Таблица ошибок: место, механизм нарушения, исправление |
| [`results/`](results/) | Файлы эксперимента на CPU: кривая потерь, история, текст и конфигурация |
| [`assets/`](assets/) | Два скриншота проверки в Google Colab |
| [`requirements.txt`](requirements.txt) | Зависимости для локального запуска |

## Воспроизведение в Google Colab

1. Открыть [Google Colab](https://colab.research.google.com/) и загрузить `dz1-attention.ipynb` через **File → Upload notebook**.
2. В меню **Runtime → Change runtime type** выбрать **T4 GPU**. Если ускоритель недоступен, можно использовать CPU.
3. Выбрать **Runtime → Run all**. В итоговой ячейке должно быть **17/17** успешно выполненных проверок.
4. Аналогично открыть и выполнить `dz1-bughunt.ipynb`. После 17 проверок выполняются 600 шагов обучения, построение графика и генерация 200 символов.
5. Для нового эксперимента сохраняются `loss_curve.png`, `loss_history.csv`, `generated_sample.txt` и `training_metrics.json` в файловой системе текущей сессии Colab. Они создаются кодом ноутбука. Чтобы сохранить результаты, нужно скачать эти файлы и сам выполненный `.ipynb`.

Оба ноутбука используют встроенный текстовый корпус, поэтому внешние датасеты и ключи API не требуются. Открытые тесты находятся внутри ноутбуков.

## Воспроизведение локально

Нужен Python версии **3.10 или новее**.

```bash
python -m pip install -r requirements.txt
jupyter notebook
```

Открыть ноутбуки по очереди и выполнить **Run All**. PyTorch в Google Colab обычно уже установлен.

## Конфигурация эксперимента

- **Seed варианта:** 42 (набор ошибок в предоставленном файле).
- **Seed обучения:** 0 (`torch.manual_seed(0)` и CUDA seed при наличии GPU).
- **Архитектура:** `context_size=64`, `d_model=128`, `n_heads=4`, `n_layers=2`, `d_ff=512`, dropout 0,1.
- **Обучение:** 600 шагов, batch size 32, AdamW, learning rate `3e-4`.
- **Корпус:** 19 уникальных символов; **400 640 параметров** модели.
- **Генерация:** 200 новых символов, `temperature=0.8`, `top_k=10`.

На CPU с Python 3.13.5 и PyTorch 2.10.0+cpu потери снизились с **3,1844** до **0,03688**. Фактические значения сохранены в [`results/loss_history.csv`](results/loss_history.csv), а параметры запуска — в [`results/training_metrics.json`](results/training_metrics.json). При выполнении на GPU и другой версии PyTorch отдельные числа могут отличаться; критерий — прохождение тестов, снижение потерь и воспроизводимость процедуры.
